# Librería Al-Andaluz
 
Aplicación web estática que simula una librería online, donde los usuarios pueden explorar el catálogo y realizar compras. 

Proyecto práctico del módulo *Diseño de Interfaces Web*, desarrollado con **HTML, CSS y JavaScript puro**, sin librerías ni frameworks de estilos.
 
El proyecto está orientado al diseño y desarrollo de interfaces web, prestando especial atención a la experiencia de usuario, la navegación intuitiva y el diseño responsive.


## Demo:

Puedes encontrarlo publicado en [GitHub Pages](https://desire-e.github.io/Libreria_Al-Andaluz/)


## Probar en entorno local:

También puedes ejecutarlo en local. Al ser una web estática, no requiere instalación de dependencias:

```bash
git clone https://github.com/Desire-e/Libreria_Al-Andaluz.git
```

Y abrir `index.html` directamente en el navegador.

> Consejo: Utilizar una extensión como Live Server evitará problemas de rutas relativas.


## Características principales
 
- Landing page con presentación de la librería y sus productos.
- Carrito de compra interactivo.
- Fichas individuales con información detallada de cada libro.
- Página de contacto para la atención al cliente.
- Banner publicitario creado con Google Web Designer.
- Diseño responsive.
- Accesibilidad.


## Tecnologías utilizadas
 
- HTML5
- CSS3
- JavaScript
- Google Web Designer (banner publicitario)
